# ARGO RACING 0.3 OCR 修正版

## iPhone Safariでの使い方
1. HTTPSで公開したサイトをSafariで開きます。
2. 「レース設定」→「データ取り込み」で写真ライブラリから出馬表画像を選びます。
3. 「画像から馬名を読み取る」を押します。初回はOCRエンジンと日本語データの読み込みに通信が必要です。
4. 読み取った馬番・馬名を確認・修正してから登録します。

## 注意
- このZIPは修正版ファイル一式です。公開済みサイトの中身を自動で更新するものではありません。
- 既存サイトへ反映するには、ホスティング先の同じ場所に index.html / sw.js / manifest.webmanifest をアップロードしてください。
- Service Workerのキャッシュ名は v04 に更新しています。反映後、Safariでページを再読み込みしてください。
- OCRはTesseract.jsと日本語学習データをCDNから読み込みます。通信制限やCDN接続失敗時はOCRできません。
- OCR結果は誤認識することがあるため、登録前に必ず確認してください。
